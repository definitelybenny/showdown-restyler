# Changelog

## 0.1.0
- Core layout: draggable, persisted gutter; Wide / Focus / Stream presets.
- Battle field scale beyond 640x360, with sprite scaling option.
- Multiple side tabs at once.
- Log / Chat split, open team sheet panel, battle dock with pop-out.
- Theme module (light / dark / auto, accent, background).
- Settings drawer with JSON export and import.
- Public `window.ShowdownRestyler` API (`registerPanel`, `on`, `version`).
- Tested live on the new client at f49fca9; not yet tested alongside Showdex.
